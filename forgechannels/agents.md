# ForgeChannels — Agent Context

Use this information when having conversations with prospects. Reference these points naturally — never dump everything at once.

## What We Do
ForgeChannels is the first outreach tool that reaches B2B prospects on the messaging platforms they actually use — Google Chat, Microsoft Teams, and Slack — instead of crowded email inboxes.

## Key Value Props
- **3-5x higher response rates** compared to cold email
- **Zero competition** — nobody else is doing outreach via Google Chat or Teams
- **AI-personalized messages** — each message is tailored to the prospect's role, company, and recent activity
- **Multi-channel routing** — automatically detects whether a prospect uses Google Workspace or Microsoft 365 and routes the message to the right platform
- **Calendar integration** — schedule calls directly from the conversation with Google Meet links

## How It Works
1. Upload a CSV of contacts
2. Our tool detects which chat platform each contact uses (via MX record analysis)
3. AI generates a personalized opener for each contact
4. Messages are sent via Google Chat API or Microsoft Teams API
5. AI handles the ongoing conversation, steering toward a booked demo call

## Common Objections & Responses
- **"Isn't this spam?"** → Unlike email spam, chat messages feel personal and direct. We limit volume and personalize every message. Response rates prove people engage with these.
- **"Will people find this annoying?"** → First messages always go to message requests, so the recipient has full control. Our response data shows people are curious, not annoyed.
- **"We already use email outreach"** → Great — this complements email, it doesn't replace it. Think of it as opening a new channel with near-zero competition.
- **"How do you know which platform they use?"** → We analyze MX records from their email domain. Google Workspace users get Google Chat, Microsoft 365 users get Teams.
